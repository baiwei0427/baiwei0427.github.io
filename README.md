# Wei Bai Personal Website

This repository contains the source for Wei Bai's personal website, a static site hosted on GitHub Pages.

## What this site contains
- Home, experience, publications, talks, and software pages
- Research profile, CV, and publication links
- Static assets such as images, PDFs, and site metadata

## Local preview
You can preview the site locally with a simple static server:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/ in your browser.

## Contributing
1. Update the relevant HTML file in the repository root.
2. Keep links, metadata, and assets consistent with the existing site structure.
3. Test the change by opening the page locally or using a static server.
4. Submit a pull request with a brief summary of the change.

## Notes
- The site is intentionally static; no build step is required.
- Images and PDFs are checked into the repository and referenced directly from the HTML files.
